# Il simulatore è un tavolo manuale, non un motore di regole

La Playtest Table permette di muovere le carte a mano (pescare, assegnare i DON!!, attaccare) e applica al massimo le regole strutturali del turno. Non esegue automaticamente gli effetti delle Card. Automatizzare migliaia di effetti diversi sarebbe un progetto a sé, sproporzionato rispetto allo scopo: provare un Deck o giocare tra amici. Richieste come "applica automaticamente l'effetto di questa carta" sono fuori scope finché questa decisione non viene rivista.
